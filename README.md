🛡️ Gerador de Senhas — JavaScript

Um gerador de senhas seguro, rápido e totalmente personalizável desenvolvido com HTML, CSS e JavaScript puro.
Projetado para ser simples, responsivo e eficiente, permitindo ao usuário criar senhas fortes com apenas um clique.

🚀 Demonstração

🔗 GitHub Pages

✨ Funcionalidades

🔐 Geração instantânea de senhas fortes

⚙️ Personalização completa

Tamanho: 4 a 64 caracteres

Letras maiúsculas

Números

Símbolos especiais

🧪 Indicador visual de segurança

Vermelho → crítico

Amarelo → médio

Verde → forte

📋 Botão de copiar senha

🔄 Botão de gerar nova senha

📱 Totalmente responsivo para mobile

🧼 Interface limpa e moderna

Tecnologia	Uso
HTML5	Estrutura do projeto

▶️ Como Executar o Projeto

Não precisa instalar nada.

Baixe ou clone o repositório:

git clone https://github.com/MauricioGonzalezDev/GERADOR-DE-SENHA-JAVASCRIPT.git


Abra o arquivo:

index.html


Pronto! O gerador estará funcionando no seu navegador.

🧠 Lógica da Geração de Senha

Concatenação dinâmica de caracteres conforme as opções marcadas

Geração aleatória com Math.random()

Cálculo de segurança baseado em:

Tamanho da senha

Uso de maiúsculas

Presença de números

Presença de símbolos

Atualização da barra de força via CSS classes:
critical, warning, safe

Ajuste do tamanho da fonte baseado em breakpoints definidos no JavaScript

🛡️ Indicador de Segurança

A barra muda de tamanho e cor conforme a força:

Cor	Força
🔴 Vermelho	Muito fraca
🟡 Amarelo	Média
🟢 Verde	Forte
🔵 Roxo (complete)	100%
